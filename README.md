# 🎵 **Musicore**

Lightweight and fast music player, which was built using Tauri and React.ts

 ## ✨ Features
- **Unified Search** — Search for tracks, albums, and artists across multiple streaming platforms simultaneously: YouTube Music, Spotify, Yandex Music
- **Smart Recommendations** — Discover new music you'll love with embedded recommendation engines that learn from what you play. No need to jump between apps.
- **Lightweight & Fast** — Built on Tauri for a native desktop experience with minimal resource usage. A fraction of the size of Electron-based alternatives.
- **Clean, Minimal UI** — Designed to stay out of your way. Focus on your music, not the interface.
- **Cross-Platform** — Runs smoothly on Windows, macOS, and Linux.
